ANDROID SAVE DATA EXTRACTION & INJECTION GUIDE

Simple instructions to extract save data from your Android device, edit here, and restore back to game.

[RECOMMENDED METHOD] Works on Android 11, 12, 13, 14, 15
  1. Install Shizuku: Download and install the Shizuku app from Google Play Store on your device.
  2. Enable Wireless Debugging: Open Developer Options in Android Settings, toggle on Wireless Debugging, open Shizuku and tap Start.
  3. Configure ZArchiver: Grant Shizuku permission to ZArchiver (ZArchiver Settings → Root → select Shizuku access type).
  4. Navigate to Save Directory: Open the following path in ZArchiver:
    /Android/data/com.AlexKosDev.lethal.company.mobile/files/
  5. Copy Save File: Locate the file named files8f5ef527ac12732ed56420 and copy it to your Download folder, then upload it here.
[USB CABLE METHOD] Via PC / Mac / Linux
  1. Connect your phone to your computer via USB (select File Transfer / MTP mode).
  2. Open File Explorer → Phone Device Name → Internal Storage → Android → data.
  3. Navigate into com.AlexKosDev.lethal.company.mobile → files.
  4. If access is restricted by Android OS folder permissions, run this ADB terminal command:
    adb pull /sdcard/Android/data/com.AlexKosDev.lethal.company.mobile/files/files8f5ef527ac12732ed56420 .
  5. The save file is now ready to upload into this editor.
[RESTORE / INJECTION PROCEDURE] After Editing
  1. Click [EXPORT SAVE] at the top right of this page. The file will download as 8f5ef527ac12732ed56420.
  2. Force Stop the Mortal Company Mobile app on your phone so it doesn't overwrite active game state.
  3. Open ZArchiver (or USB File Transfer) and move the newly downloaded file into:
    /Android/data/com.AlexKosDev.lethal.company.mobile/files/
  4. Select Overwrite / Replace when prompted that the file already exists.
  5. Launch Mortal Company Mobile, tap Continue Game, and enjoy your updated save!
