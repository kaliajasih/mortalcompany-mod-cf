PANDUAN MENGAMBIL & MENGINJECT SAVE DATA ANDROID

Langkah mudah mengekstrak file save dari HP ke website lalu mengembalikannya ke game.

[METODE REKOMENDASI] Bekerja di Android 11, 12, 13, 14, 15
  1. Install Shizuku: Unduh aplikasi Shizuku dari Google Play Store di HP Anda.
  2. Aktifkan Wireless Debugging: Di Opsi Pengembang (Developer Options) HP, aktifkan "Wireless Debugging" dan pairing dengan kode 6-digit ke Shizuku, lalu tekan "Start".
  3. Buka Izin di ZArchiver: Di ZArchiver > Pengaturan > Root/Akses > pilih jenis akses "Shizuku".
  4. Buka Folder Save: Buka /Android/data/com.AlexKosDev.lethal.company.mobile/files/
  5. Salin Save: Cari file bernama files8f5ef527ac12732ed56420 dan salin ke folder Download, lalu upload ke website ini.
[METODE KABEL USB / ADB] Via Komputer / Laptop

Sambungkan HP ke laptop dengan kabel data, nyalakan USB Debugging, lalu jalankan perintah ADB di PowerShell / Terminal:

adb pull /sdcard/Android/data/com.AlexKosDev.lethal.company.mobile/files/files8f5ef527ac12732ed56420 .
[RESTORE / INJECT HASIL EDIT KE HP]
  1. Klik tombol kuning [UNDUH SAVE (8f5ef527...)] di bagian atas website ini.
  2. Cadangkan file asli di HP Anda dengan menambahkan akhiran .bak.
  3. Pindahkan file hasil unduhan ke dalam folder:
    /Android/data/com.AlexKosDev.lethal.company.mobile/files/files8f5ef527ac12732ed56420
  4. Buka game Mortal Company Mobile di HP, pilih Continue, dan item duplikat serta uang Anda langsung aktif!
