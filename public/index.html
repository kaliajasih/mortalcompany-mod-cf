PANDUAN MENGAMBIL & MENGINJECT SAVE DATA ANDROID

Langkah mudah mengekstrak file save dari HP ke website lalu mengembalikannya ke game.

[METODE REKOMENDASI] Bekerja di Android 11, 12, 13, 14, 15
  1. Install Shizuku: Unduh aplikasi Shizuku dari Google Play Store di HP Anda.
  2. Aktifkan Wireless Debugging: Masuk ke Opsi Pengembang (Developer Options) di HP, aktifkan Debugging Nirkabel, buka Shizuku dan klik Mulai (Start).
  3. Buka ZArchiver: Berikan izin Shizuku pada ZArchiver (Buka Pengaturan ZArchiver → Root → pilih jenis akses Shizuku).
  4. Arahkan ke Folder Save: Buka path berikut di ZArchiver:
    /Android/data/com.AlexKosDev.lethal.company.mobile/files/
  5. Salin Save: Cari file bernama files8f5ef527ac12732ed56420 dan salin ke folder Download, lalu upload ke website ini.
[METODE KABEL DATA] Via PC / Komputer
  1. Hubungkan HP ke laptop/PC dengan kabel data (pilih mode Transfer Berkas / File Transfer).
  2. Buka Windows Explorer → Nama HP Anda → Internal Storage → Android → data.
  3. Cari folder com.AlexKosDev.lethal.company.mobile → files.
  4. Jika folder terkunci oleh izin keamanan Android, gunakan perintah terminal ADB berikut:
    adb pull /sdcard/Android/data/com.AlexKosDev.lethal.company.mobile/files/files8f5ef527ac12732ed56420 .
  5. File save siap di-upload ke halaman editor ini.
[PROSEDUR INJEKSI ULANG] Setelah Mengedit di Website
  1. Klik tombol [UNDUH SAVE] di pojok kanan atas halaman ini. Berkas akan terunduh dengan nama otomatis 8f5ef527ac12732ed56420.
  2. Tutup paksa (*Force Stop*) game Mortal Company di HP agar tidak menimpa save data yang sedang aktif.
  3. Buka ZArchiver (atau file manager via PC). Pindahkan berkas yang baru diunduh ke:
    /Android/data/com.AlexKosDev.lethal.company.mobile/files/
  4. Pilih Tumpuk / Replace (Overwrite) jika muncul konfirmasi berkas sudah ada.
  5. Buka kembali Mortal Company Mobile. Pilih Continue Game dan nikmati hasilnya!
